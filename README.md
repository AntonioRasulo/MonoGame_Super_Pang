Falls Off The Balls is a roguelike arcade game where all you have to do is to shot to balls and flying demon bats.  In the runs you can collect coins that can be used in the shop to buy power up and skills for you character and gun. You can save your game and save the scores on a leader board.

Controls

You can play the game with mouse/keyboard or a gamepad.

Keyboard controls
Key	Alternate Key	Action
A	Left Arrow	Move Left
D	Right Arrow	Move Right
Spacebar		Shoot
Escape		Toggle pause/quit game
Enter		Confirm menu action

Gamepad controls
Key	Alternate Key	Action
D-Pad Left	Left Thumbstick Left	Move Left
D-Pad Right	Left Thumbstick Right	Move Right
Start		Toggle pause
A		Shoot/Confirm menu action

Developed with MonoGame
